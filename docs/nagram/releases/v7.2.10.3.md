Nagram Desktop 7.2.10.3，基于 Telegram Desktop 7.2.10。完整功能列表见 [7.2.10-pre.1](https://github.com/NextAlone/Nagram-Qt/releases/tag/v7.2.10-pre.1)，这里只列出相对 [7.2.10-pre.2](https://github.com/NextAlone/Nagram-Qt/releases/tag/v7.2.10-pre.2) 的变化。

从这个版本起，版本号写作“上游版本.修订号”：`7.2.10` 是所基于的 Telegram Desktop 版本，最后一位是 Nagram 自己的修订号。此前的 `7.2.10-pre.1`、`7.2.10-pre.2` 相当于修订号 1 和 2。

功能主要在 macOS 上验证过，Windows 和 Linux 只通过了编译、单元测试和启动冒烟测试；自动更新只在 macOS 上实测过。发现问题请到 [Issues](https://github.com/NextAlone/Nagram-Qt/issues) 反馈。

## 新增

- 自动更新：应用会自己检查并安装新版本，开关在“设置 → 高级”。更新包从本仓库的发行页下载，只接受 Nagram 的密钥签名的更新包。此前的预发布版本没有更新器，需要手动安装这一版。
- 发送前翻译：在设置里打开后，聊天菜单里出现“发送前翻译”，为这个聊天选定语言。之后在该聊天发送文字时先显示翻译预览，由你决定发送译文还是原文。
- 免打扰时段：按开始时间、结束时间和星期设置，可以为联系人私聊、置顶聊天、提及和回复、关键词提醒设置例外。
- 关键词提醒：最多 50 条规则，支持普通文本和正则表达式，命中时即使聊天已静音也会通知。
- 清理不用的聊天：列出已注销的账号，以及六个月没有消息的机器人、群组和频道，可以批量归档或退出。置顶的聊天、收藏夹、你拥有或管理的群组和频道不会被列出。
- 消息菜单新增“复制为 Markdown”，默认隐藏。
- Windows 除便携版外，新增安装程序。
- Linux 发行包解开后是一个 `Nagram` 目录，附带桌面入口、图标等打包用的文件。

| 平台 | 文件 |
| --- | --- |
| macOS（Apple 芯片与 Intel） | `Nagram-7.2.10.3-macos.dmg`（磁盘镜像）、`Nagram-7.2.10.3-macos.zip` |
| Windows x64 | `Nagram-7.2.10.3-windows-x64-setup.exe`（安装程序）、`Nagram-7.2.10.3-windows-x64.zip`（便携版） |
| Windows ARM64 | `Nagram-7.2.10.3-windows-arm64-setup.exe`（安装程序）、`Nagram-7.2.10.3-windows-arm64.zip`（便携版） |

## 安装

### macOS

- **磁盘镜像**（`.dmg`）：打开后把 Nagram 拖到旁边的 Applications 文件夹。
- **压缩包**（`.zip`）：解压得到 `Nagram.app`，放进“应用程序”文件夹。

两种方式装的是同一个应用，都会自行更新。

### Windows

- **安装程序**（`-setup.exe`）：装到当前用户的 `%APPDATA%\Nagram Desktop`，程序和数据都在这里。不需要管理员权限，会创建开始菜单快捷方式（桌面快捷方式可选），可以在系统的“应用”里卸载。
- **便携版**（`.zip`）：解压到一个可写的文件夹，运行 `Nagram.exe`。数据就存在这个文件夹里，整个文件夹可以直接拷走；放在不可写的位置时，数据会改存到 `%APPDATA%\Nagram Desktop`。

两种方式装的都会自行更新。

### Arch Linux（AUR）

包名是 `nagram-desktop-bin`，安装的就是本页的 Linux 发行包：

```bash
yay -S nagram-desktop-bin
```

没有 AUR 助手时：

```bash
git clone https://aur.archlinux.org/nagram-desktop-bin.git
cd nagram-desktop-bin
makepkg -si
```

这样装的由 pacman 更新，应用内的自动更新是关闭的。

### Nix

仓库自带 flake，安装的同样是本页的 Linux 发行包，只支持 x86_64-linux，需要启用 flakes：

```bash
nix run github:NextAlone/Nagram-qt
```

装进用户环境：

```bash
nix profile install github:NextAlone/Nagram-qt
```

在 NixOS 或 home-manager 的 flake 里，把 `github:NextAlone/Nagram-qt` 加为输入，然后使用 `packages.x86_64-linux.default`。程序在隔离的 FHS 环境里运行，由 Nix 更新，应用内的自动更新是关闭的。

AUR 和 Nix 的包在本版本发布后由 CI 更新，会比本页晚几分钟。

### 其他 Linux 发行版

解开 `tar.xz`，运行 `Nagram/Nagram`。放在可写的位置时会自行更新。

安装包没有开发者签名和公证。macOS 首次打开需要在“系统设置 → 隐私与安全性”里允许，Windows 可能弹出 SmartScreen 提示。

Nagram Desktop 使用独立的数据目录，不会读取或修改 Telegram Desktop 的数据。
