Nagram Desktop 的第二个预发布版本，基于 Telegram Desktop 7.2.10。完整功能列表见 [7.2.10-pre.1](https://github.com/NextAlone/Nagram-Qt/releases/tag/v7.2.10-pre.1)，这里只列出相对它的变化。

这是预发布版本：功能主要在 macOS 上验证过，Windows 和 Linux 只通过了编译、单元测试和启动冒烟测试。发现问题请到 [Issues](https://github.com/NextAlone/Nagram-Qt/issues) 反馈。

## 新增

- 受保护的消息可以以副本形式复读和转发。
- 在评论区里复读时，副本作为对原帖的回复发送，并停留在评论区。
- 文件夹列表里可以显示归档和收藏夹。
- 消息的浏览数旁边显示转发数。
- 圆角大小改用滑块设置。
- 按日期范围导出对话时只拉取所选范围内的消息，不再遍历整个对话。

## 修复

- 第二次备份设置到收藏夹时应用崩溃。
- 鼠标滚轮事件被失效的抓取劫持，导致滚动失灵。
- Windows：窗口去掉系统原生标题栏；子菜单项无法点击；托盘图标的未读点不再盖住 N 字。
- Linux：Nagram 不在 `PATH` 里时无法打开 `tg://` 链接。
- 非 macOS 平台不再显示 Apple Intelligence 选项。
- 从文件夹打开归档后可以返回原文件夹。
- 消息菜单：Nagram 的动作排在底部信息栏之上；已读和编辑时间一行与菜单项对齐；最近会话使用历史图标。
- 主菜单在内容放得下时不再滚动。
- 设置页：各分栏有了自己的图标；反应开关标明对应的聊天类型；服务页的说明更简短；顶栏工具按钮的颜色与其他顶栏按钮一致。

## 安装包

| 平台 | 文件 |
| --- | --- |
| macOS | `Nagram-7.2.10-pre.2-macos.zip` |
| Windows x64 | `Nagram-7.2.10-pre.2-windows-x64.zip` |
| Windows ARM64 | `Nagram-7.2.10-pre.2-windows-arm64.zip` |
| Linux x86_64 | `Nagram-7.2.10-pre.2-linux-x86_64.tar.xz` |

安装包没有开发者签名和公证。macOS 首次打开需要在“系统设置 → 隐私与安全性”里允许，Windows 可能弹出 SmartScreen 提示。应用内没有自动更新，新版本请到本页下载。

Nagram Desktop 使用独立的数据目录，不会读取或修改 Telegram Desktop 的数据。
