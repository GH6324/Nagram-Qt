Nagram Desktop 的第一个预发布版本，基于 Telegram Desktop 7.2.10。增强功能集中在“设置 → Nagram”里，全部默认关闭或保持 Telegram 的默认行为。

这是预发布版本：功能主要在 macOS 上验证过，Windows 和 Linux 只通过了编译和单元测试。发现问题请到 [Issues](https://github.com/NextAlone/Nagram-qt/issues) 反馈。

## 翻译与 AI

- 多种翻译服务可选，包括 Google、Microsoft、Yandex、DeepL，以及自己的大模型接口。
- 大模型翻译可自定义接口地址、模型和提示词，内置常见厂商预设，支持 OpenAI 与 Anthropic 两种协议。
- 按设备、账号、对话三层设置自动翻译；翻译整个对话时可以使用所选的翻译服务。
- 大模型翻译可带上近期消息作为上下文。
- 用大模型总结单条或多条消息。
- 自定义语音转文字服务（OpenAI 兼容接口），可批量转写选中的语音消息。
- 发送前翻译输入内容，阅读时简繁转换。

## 文本与输入

- 盘古之白：发送、编辑或阅读时在中西文之间加空格。
- 选中文字时显示格式工具栏，可关闭自动 Markdown，设置默认代码语言。
- 输入框各按钮可单独隐藏，鼠标悬停时不弹出表情面板和附件菜单。
- 发送贴纸、GIF、语音、圆形视频前确认或预览；私聊通话前确认。
- 快捷回复，点击机器人命令时先填入输入框，默认不显示链接预览。

## 消息

- 复读、无引用复读、无引用转发。
- 消息过滤：用关键词或正则表达式遮盖、折叠或隐藏消息，支持全局规则和按对话、话题覆盖。
- 消息菜单每一项可设为显示、隐藏或按住 Option / Alt 才显示。
- 多选后合并为一条文本、批量操作、选择此人的消息、选择区间内的消息。
- 消息截图，可使用内置主题或云主题。
- 时间显示秒、转发消息显示原始发送时间、显示消息 ID、精确的浏览数和回复数。
- 隐藏赞助消息、消息反应、“已编辑”标记、会员标识、推荐频道等。

## 聊天列表与文件夹

- 紧凑列表，可调消息预览行数，隐藏收藏夹和归档的消息预览。
- 启动时打开指定文件夹，隐藏“全部会话”，在文件夹中显示归档入口，隐藏未读数。
- 会话排序，记住最近会话，恢复阅读位置。
- 置顶已满时在本机继续置顶。
- 隐藏动态、Premium 推广、生日提示和代理赞助频道。

## 媒体与贴纸

- 贴纸大小、最近使用数量，隐藏推荐贴纸、推荐表情和 GIF 推荐分类。
- 收藏贴纸已满时在本机保留被挤出的贴纸。
- 把贴纸包导出到指定目录并自动同步；导出和导入已安装贴纸包列表。
- 语音消息码率，关闭群组通话的音频处理，自定义音乐封面地址。
- 关闭视频自动播放，GIF 显示播放控制。

## 界面与资料

- 10 套应用图标，可调消息气泡圆角、头像圆角和文字消息宽度。
- 自定义主菜单项，通知延迟，隐藏应用图标角标。
- 资料页显示 ID、数据中心和注册时间。
- 遮盖手机号，演示模式，添加联系人时默认不分享手机号。
- 允许复制和保存受保护的内容，忽略内容限制，自动显示敏感媒体。

## 网络与链接

- IP 版本策略，使用系统 DNS，自定义 DoH 地址，不请求备用服务器地址。
- 下载加速和上传加速。
- 链接规则；按链接自动查询 inline 机器人，可添加本地规则。
- 网页应用窗口大小、平台标识，指定链接改用浏览器打开。
- 打开 Telegram 官方网页时不自动登录。

## 账号与备份

- 导出和导入设置，查看已修改的设置，复制诊断信息。
- 把设置备份到收藏夹并从收藏夹恢复，可在设置变更后自动备份。备份是明文文件，不包含服务密钥。

## 安装包

| 平台 | 文件 |
| --- | --- |
| macOS | `Nagram-7.2.10-pre.1-macos.zip` |
| Windows x64 | `Nagram-7.2.10-pre.1-windows-x64.zip` |
| Windows ARM64 | `Nagram-7.2.10-pre.1-windows-arm64.zip` |
| Linux x86_64 | `Nagram-7.2.10-pre.1-linux-x86_64.tar.xz` |

安装包没有开发者签名和公证。macOS 首次打开需要在“系统设置 → 隐私与安全性”里允许，Windows 可能弹出 SmartScreen 提示。应用内没有自动更新，新版本请到本页下载。

Nagram Desktop 使用独立的数据目录，不会读取或修改 Telegram Desktop 的数据。
